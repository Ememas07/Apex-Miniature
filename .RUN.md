# Apex Miniature — Command & Automation Runbook

A complete reference of workspace commands for virtual environments, reinforcement learning training, benchmarking, physics tuning, telemetry, acoustic fitting, and 3D car asset conversion.

---

## 1. Python Environment Setup (`.venv-rl`)

The reinforcement learning pipeline uses a dedicated virtual environment named `.venv-rl` with PyTorch, Gymnasium, Stable-Baselines3, and scientific computing packages.

### Create and Activate Virtual Environment

```powershell
# Create virtual environment in workspace root
python -m venv .venv-rl

# Activate in PowerShell
.\.venv-rl\Scripts\Activate.ps1

# Activate in Command Prompt (CMD)
.\.venv-rl\Scripts\activate.bat

# Activate in Git Bash
source .venv-rl/Scripts/activate
```

### Install Required Dependencies

```powershell
# Upgrade pip
python -m pip install --upgrade pip

# Install PyTorch (CPU version - recommended for headlessEnv RL subprocess workers)
pip install torch --index-url https://download.pytorch.org/whl/cpu

# OR Install PyTorch with CUDA (if using GPU acceleration)
pip install torch --index-url https://download.pytorch.org/whl/cu121

# Install core RL, Gym, and Data Analysis packages
pip install gymnasium stable-baselines3 numpy scipy tensorboard sounddevice pillow tqdm rich
```

### Install Node / TSX Bridge

Python RL scripts communicate with the physics simulation engine via `npx tsx scripts/headlessEnv.ts`. Ensure Node dependencies are installed:

```powershell
npm install
```

## 2. Policy Benchmarking & Evaluation (`evalAllTracksAndCars.py`)

Deterministic multi-environment benchmark runner evaluating AI driving policies across all 43 circuits and 58 cars. Outputs detailed JSON and CSV metrics to `audit/`.

### Run Benchmarks

```powershell
# Default benchmark on v1 weights (src/game/aiPolicyWeights_v1.json)
python -u scripts/evalAllTracksAndCars.py

# Benchmark all 4 model variants (v1, v2, v3, v4) sequentially
python -u scripts/evalAllTracksAndCars.py --all --out audit/eval_matrix.json

# Benchmark a specific checkpoint / variant
python -u scripts/evalAllTracksAndCars.py --weights src/game/aiPolicyWeights_v2.json --out audit/bench_results/v2_eval.json
python -u scripts/evalAllTracksAndCars.py --weights src/game/aiPolicyWeights_v3.json --out audit/bench_results/v3_eval.json
python -u scripts/evalAllTracksAndCars.py --weights src/game/aiPolicyWeights_v4.json --out audit/bench_results/v4_eval.json

# Fast benchmark on targeted tracks & cars with smaller batch size
python -u scripts/evalAllTracksAndCars.py --tracks spa-francorchamps laguna-seca monza --cars ferrari-499p porsche-911-gt3-r --envs 8 --max-steps 4000

# Benchmark all selectable liveries (not just base car specs)
python -u scripts/evalAllTracksAndCars.py --all-liveries

# High-concurrency evaluation (24 workers, 6000 step budget)
python -u scripts/evalAllTracksAndCars.py --envs 24 --max-steps 6000 --out audit/bench_results/full_grid.json
```

### Automated Benchmark Suite (PowerShell)

Automatically benchmarks all 4 policy variants with timestamped file outputs (`HH-mm-ss-dd-MM-yy_v{1..4}.json`):

```powershell
# Run benchmark suite across v1..v4
.\scripts\run_all_benchmarks-v2.ps1

# Custom output directory or file prefix
.\scripts\run_all_benchmarks-v2.ps1 -Prefix "finetune" -OutDir "audit/bench_results"
```

## 4. Reinforcement Learning Training (PPO)

Trains neural driving policies (`43` input observation dimensions, `3` continuous action outputs: `[steer, throttle, brake]`).

### Specialized PPO Variants

| Script | Variant Name | Focus & Architectural Details |
|---|---|---|
| `scripts/trainPPO_v1_clean_apex.py` | `v1_clean_apex` | Safety, survival, anti-stall, higher off-track & wall crash penalties, floor-speed penalty |
| `scripts/trainPPO_v2_momentum.py` | `v2_momentum` | Minimum speed preservation, jerk reduction, throttle/brake overlap penalty, smooth cornering |
| `scripts/trainPPO_v3_aggressive_pace.py` | `v3_aggressive_pace` | 128-hidden unit MLP, 0.60 forward progress multiplier, high apex speed, kerb-riding tolerance |
| `scripts/trainPPO_v4_curriculum.py` | `v4_curriculum` | 2-phase curriculum: 45% solo hotlapping followed by 55% multiclass & neural self-play traffic |

### Execution Commands

```powershell
# Standard training run (32 parallel envs, 256 rollout steps, 1000 updates)
python -u scripts/trainPPO_v1_clean_apex.py --envs 32 --steps 256 --updates 1000
python -u scripts/trainPPO_v2_momentum.py --envs 32 --steps 256 --updates 1000
python -u scripts/trainPPO_v3_aggressive_pace.py --envs 32 --steps 256 --updates 1000
python -u scripts/trainPPO_v4_curriculum.py --envs 32 --steps 256 --updates 1000

# Fine-tuning with reduced learning rate on specific tracks
python -u scripts/trainPPO_v1_clean_apex.py --envs 24 --steps 256 --updates 1500 --no-reset-best --actor-lr 5e-5 --tracks monaco montreal detroit-street laguna-seca hungaroring shanghai yas-marina vir

python -u scripts/trainPPO_v3_aggressive_pace.py --envs 24 --steps 256 --updates 1500 --no-reset-best --actor-lr 5e-5 --tracks daytona-road bahrain portimao mosport suzuka spa-francorchamps laguna-seca vir

# Train from scratch (ignores existing weights)
python -u scripts/trainPPO_v2_momentum.py --scratch --reset-best --updates 2000

# Override entropy end floor or exploration spread
python -u scripts/trainPPO_v2_momentum.py --ent-end 0.002 --max-std-end 0.40
```

### Batch & Background Training Orchestration

```powershell
# Run all 4 PPO training jobs in parallel background jobs
.\scripts\run_all_trainings.ps1 -env 24 -steps 256 -updates 1000

# Run all 4 PPO training jobs in separate interactive PowerShell windows
.\scripts\run_all_trainings.ps1 -env 24 -steps 256 -updates 1000 -SeparateWindows

# Run fine-tune job pipeline
.\scripts\run_finetune_jobs.ps1
```

### Legacy & Telemetry Training

```powershell

python scripts/trainImitation.py --data "telemetry/*.json" --epochs 60 --batch-size 256 --lr 1e-3

```

## 6. Acoustic Engine Profiler (`fitSoundFromVideo.py`)

Fits synthesized audio harmonics and resonance presets for `audioEngine.ts` from real-world onboard video/audio recordings (`.mp4`, `.wav`, `.m4a`) using Differential Evolution.

```powershell
# Basic 8-cylinder engine sound fit from video
python scripts/fitSoundFromVideo.py assets/engine_clip.mp4 --cylinders 8 --idle 1100 --redline 8800 --out src/game/engine_v8.json --save-preview preview_v8.wav

# V6 Turbo / GT3 / LMP2 fit with custom analysis duration and iterations
python scripts/fitSoundFromVideo.py assets/v6_onboard.wav --cylinders 6 --idle 1200 --redline 8500 --duration 3.0 --iters 150 --popsize 12 --out src/game/engine_v6.json

# V10 / V12 High-RPM Formula fit
python scripts/fitSoundFromVideo.py assets/v10_f1.mp4 --cylinders 10 --idle 3500 --redline 18500 --start 4.5 --duration 2.0 --iters 100
```

## 7. 3D Car Asset Conversion (`objToLowPoly.mjs`)

Batch decimation and geometry alignment converter for Assetto Corsa `.kn5` or raw `.obj` car files into game-ready low-poly `.obj`/`.mtl` models matching `carBuilder.ts` coordinates (+Z nose forward, ground aligned at y=0, separate wheel nodes `WHEEL_LF`, `WHEEL_RF`, `WHEEL_LR`, `WHEEL_RR`).

```powershell
# Convert all models from models/raw-cars into models/lowpoly-cars
npm run convert:cars

# Direct execution with node
node scripts/objToLowPoly.mjs

# Filter single car by name
node scripts/objToLowPoly.mjs --filter ferrari-499p
node scripts/objToLowPoly.mjs --filter porsche

# Custom target triangle budget (default: 12000)
node scripts/objToLowPoly.mjs --tris 8000

# Custom decimation ratio instead of fixed tri count
node scripts/objToLowPoly.mjs --ratio 0.15

# Override real-world length in meters (or scale factor)
node scripts/objToLowPoly.mjs --filter oreca-07 --length 4.75
node scripts/objToLowPoly.mjs --scale 1.05

# Strip glass / transparent windshield nodes
node scripts/objToLowPoly.mjs --exclude-glass

# Specify custom input and output directories
node scripts/objToLowPoly.mjs "models/raw-cars" "models/lowpoly-cars" --tris 10000
```
