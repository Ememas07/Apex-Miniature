# Apex Miniature — Command & Automation Runbook

Clean reference for the unified **3-script** toolchain:
1. **`scripts/trainPPO.py`** — Single PPO trainer (`v1`, `v2`, `starts`, plus optional `--bc-dataset` warm-start; uses internal `scripts/headlessEnv.ts`).
2. **`scripts/benchAndAudit.py`** — Single deterministic benchmark & Markdown audit generator across all tracks & cars.
3. **`scripts/objToLowPoly.mjs`** — 3D `.kn5`/`.obj` car asset converter (`npm run convert:cars`).

> **Model Naming Rotation Rule**: Only **`v1`**, **`v2`**, and **`starts`** exist. Every new generation is trained as **`v2`**; when a newer generation arrives, the previous `v2` rotates into `v1`.

---

## 1. Python Environment Setup (`.venv-rl`)

```powershell
# Create & activate virtual environment
python -m venv .venv-rl
.\.venv-rl\Scripts\Activate.ps1

python -m pip install --upgrade pip
pip install torch --index-url https://download.pytorch.org/whl/cu121

# Install Node dependencies (required by headlessEnv.ts bridge)
npm install
```

## 2. Training AI Policies (`scripts/trainPPO.py`)

Both `v1` and `v2` use the **59-dim advanced physics observation vector** and a **3×192 ResMLP + LayerNorm + ObsNorm** architecture, automatically exporting both `.json` and compact `ANB1` `.bin` weights (synced to `public/models/policies/`).

| Variant (`--variant`) | Purpose | Default Spec (9800X3D + RTX 4060) |
|---|---|---|
| `v1` | **Physics Master** (current V9.2 new-physics spec) | `59-in -> 3x192 ResMLP`, 96 envs, 12 workers, 512 steps, 2500 updates |
| `v2` | **Section 4 Racecraft & Turn-1 Master** (Turn-1 cold-tire braking, multi-class traffic & blue-flag passing, dense packs, wet crossovers) | `59-in -> 3x192 ResMLP`, 96 envs, 12 workers, 512 steps, 2500 updates |
| `starts` | **Grid Launch & Turn-1 Specialist** (standing/rolling 2×2 starts into Turn 1) | `43-in -> 2x128 ResMLP`, 48 envs, 8 workers, 512 steps, 1200 updates |

### Ready-to-Run Training Commands

```powershell
# 1) Train V1 (current V9.2 new-physics model, from scratch on 59-dim obs)
python -u scripts/trainPPO.py --variant v1 --scratch --device cuda

# 2) Train V2 (new Section 4 Racecraft & Turn-1 Master — warm-start from V1 once V1 finishes, or from scratch)
python -u scripts/trainPPO.py --variant v2 --init-from src/game/aiPolicyWeights_v1.json --reset-best --device cuda
# Or train V2 completely from scratch:
python -u scripts/trainPPO.py --variant v2 --scratch --device cuda

# 3) Retrain Starts Specialist with Turn-1 braking awareness (optional)
python -u scripts/trainPPO.py --variant starts --device cuda

# 4) Quick validation run (400 updates)
python -u scripts/trainPPO.py --variant v2 --quick --device cuda

# 5) Behavioral Cloning warm-start from human laps exported via Pause/Results UI (.jsonl)
python -u scripts/trainPPO.py --variant v2 --bc-dataset datasets/apex_bc_dataset.jsonl --bc-epochs 12 --device cuda

# 6) Targeted fine-tuning on specific circuits or cars
python -u scripts/trainPPO.py --variant v2 --envs 64 --workers 8 --updates 600 --tracks monaco baku spa-francorchamps laguna-seca monza --device cuda
```

> If you are already mid-training an older `aiPolicyWeights_v9_2.json` locally and want to promote it into `v1` and continue training:
> ```powershell
> Copy-Item src/game/aiPolicyWeights_v9_2.json src/game/aiPolicyWeights_v1.json -Force
> python -u scripts/trainPPO.py --variant v1 --device cuda
> ```

## 3. Benchmarking & Audits (`scripts/benchAndAudit.py`)

Runs deterministic multi-track × multi-car evaluations and writes both raw JSON (`audit/bench_results/bench_<ts>.json`) and a condensed Markdown audit (`audit/audit_result_<ts>.md`).

```powershell
# Benchmark & audit V1
python -u scripts/benchAndAudit.py --variant v1 --envs 12

# Benchmark & audit V2
python -u scripts/benchAndAudit.py --variant v2 --envs 12

# Benchmark & audit both V1 and V2 side-by-side
python -u scripts/benchAndAudit.py --all --envs 12

# Fast targeted audit on key technical & high-speed circuits
python -u scripts/benchAndAudit.py --variant v2 --tracks spa-francorchamps monza monaco laguna-seca silverstone --cars f1-26-mercedes ferrari-499p oreca-07 porsche-911-gt3-r --envs 8

# Compare against a previous JSON baseline
python -u scripts/benchAndAudit.py --variant v2 --baseline audit/bench_results/bench_prev.json
```

## 4. 3D Car Asset Conversion (`scripts/objToLowPoly.mjs`)

Converts Assetto Corsa `.kn5` or raw `.obj` models from `models/raw-cars/` into aligned low-poly assets in `models/lowpoly-cars/`.

```powershell
# Convert all cars in models/raw-cars/
npm run convert:cars

# Convert a single car with custom triangle budget
node scripts/objToLowPoly.mjs --filter ferrari-499p --tris 12000

# Override real-world length or strip glass meshes
node scripts/objToLowPoly.mjs --filter oreca-07 --length 4.75 --exclude-glass
```
